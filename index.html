代码在哪里跑

  1. 默认在浏览器里跑，打开网页就能写代码，numpy 和 pandas 都能用。
  2. 想用自己电脑上的 Python，下载本仓库后运行 python runner/serve.py，在网页的运行设置里填 http://127.0.0.1:8760。
  3. 想用远程服务器，运行 python runner/connect_server.py --host 服务器地址 --user 用户名，它会把后端装到服务器上并映射到本机同一个地址。
